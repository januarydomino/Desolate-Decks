# Desolate Decks

Desolate Decks is a Balatro texture pack which utilizes [Malverk](https://github.com/Eremel/Malverk) to please certain [Clay Golems](https://github.com/ArgilRants) by changing every deck in the game to have custom, Abandoned Deck themed textures.

This was created as a test mod to familiarize myself with Malverk, extremely simple coding, and overall how the modding portion of Balatro works. This mod has been exclusively and proudly made by human hands.
