# Desolate Decks

Desolate Decks is a Balatro texture pack which utilizes [Malverk](https://github.com/Eremel/Malverk) to please certain [Clay Golems](https://github.com/ArgilRants) who love [Abandoned Deck](https://balatrowiki.org/w/Abandoned_Deck) by changing every deck in the game to have custom, Abandoned Deck themed textures.
